About

Montana raised.
Terminal native.

I grew up in Montana taking things apart to see how they worked. Most of them eventually went back together. That habit never really left — it just moved from small engines and bicycle parts to Linux services, storage, and the occasional stubborn Python script.

At 21 I moved to northern California and lived off the grid for a while, learning how to make systems work with limited resources and no room for waste. These days I’m back in Montana, where I run a home server that handles my files, photos, music, calendars, and backups.

That server is my classroom. I’ve learned more from keeping it alive than from any tutorial: how to plan a backup, how to recover from a bad update, and how to document a fix so future-me doesn’t have to rediscover it. I’m looking to bring that same careful, hands-on approach to a team.

Capabilities

What I bring to the rack.

A practical mix of Linux administration, automation, and front-end work — built by maintaining systems that have to keep working after the tutorial ends.

  1. 01

    Linux and self-hosting

    Install, update, and troubleshoot Linux services. Docker containers, systemd units and timers, storage mounts, and the unglamorous maintenance that keeps a server healthy.

  2. 02

    Automation and scripting

    Python and Bash for the repetitive work: API syncs, file pipelines, scheduled jobs, and small tools that remove a manual step.

  3. 03

    Networking and access

    Tailscale-only remote access and a strong preference for keeping admin interfaces off the public internet.

  4. 04

    Backup and recovery

    Nightly restic backups, an off-site mirror, and weekly read-verification. A backup is still unproven until a full restore succeeds.

  5. 05

    Web development

    Hand-written HTML and CSS, plus small Flask applications. Enough front end to build a clear dashboard and enough restraint to keep it fast.

  6. 06

    Data and SQL

    SQL fundamentals, CSV and log processing, and Python for turning raw output into something a person can actually read.
